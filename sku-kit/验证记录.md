日期：2026-11-06。本机环境：macOS Apple Silicon、Python 3.12.14、Pillow 13.0.0。

## 本机已验证

- 113 项 Python 测试与 8 项 JavaScript 测试通过；文档相对链接、必需社区文件、YAML 表单、源码语法和包元数据检查通过。

- 从仓库外的全新临时目录运行三个 console 入口及 `python -m sku_kit`。CLI 实际执行检查、清单、打包和交付核验；MCP 实际握手、检查与打包；网页入口实际提供静态资源、HTTP 检查和交付包核验。
- 对原始 CSV、PNG / JPEG 及导出字节进行核对；换成另一张有效图片后，交付包核验拒绝；缺图阻断和外部来源拒绝仍有效。

- 版本统一为 0.5.0，运行依赖升级到 Pillow 13 安全修复基线，最低源码 Python 要求为 3.11；桌面用户无需安装 Python。

## 持续验证

CI 对 Ubuntu 的 Python 3.11 / 3.13、Windows 的 Python 3.13、macOS 的 Python 3.13 运行源码与安装包检查。wheel 会装入干净虚拟环境，从独立工作目录验证实际入口，不以源码可运行代替安装可运行。

桌面任务另外在 Windows / macOS 原生 runner 构建，解压最终 ZIP 后启动并检查。发布任务需本次源码 / 安装 CI 及两平台桌面任务都通过，才上传新预览版。此文描述验证机制，不预先声明未完成的远端运行成功；具体结果以该提交的 Actions 记录为准。

没有发布到 PyPI，没有商业代码签名或 macOS 公证，也没有所有 AI 宿主或所有系统的兼容保证。包内 SHA-256 清单不等于身份签名。业务资料不会因测试或反馈而自动上传。

## 实际修复

- Windows 原生 CI 发现恶意路径 ZIP 测试构造会被平台自动规范化；现保留真实恶意成员名并增加模拟回归，不跳过或放宽防护。

- 长中文图片名/表名截断时可能丢掉扩展名；现为普通短后缀预留空间。
- CSV 分隔符嗅探可能启用自动去前导空格，导致原编号空格被悄悄消除；现保留原值交由引擎报错。
- CSV 引号中的单元格换行曾导致行号按物理文本行计数；现按表格记录定位，保留空行位置。

测试文件在本机临时工作目录生成，不随源码或桌面版发布。没有客户私有资料。
